🤖 3. AI Chatbot Technical Architecture

The chatbot is built to deliver instant, contextual responses without relying on paid cloud APIs that might fail or expire during evaluation:

  • Client-Side NLU & Token Matcher: Employs weighted token scoring, entity extraction, and synonym expansion. Handles varied phrasings including "What projects has he worked on?", "What technologies does he know?", "Show me his resume", "What are his coding profiles?", and "What is his CGPA?".
  • Interactive Action Triggers: Bot responses render interactive HTML action cards with clickable buttons that directly launch the Resume Modal, initiate PDF downloads, or open verified LeetCode and LinkedIn profiles.
  • Zero-Dependency Audio Synthesis: Generates responsive sound effects using the browser's native Web Audio API oscillators without requiring external MP3 downloads.
  • Speech Recognition & Synthesis: Supports hands-free voice input via the Web Speech API (webkitSpeechRecognition) and text-to-speech narration (speechSynthesis).
  • Dual Mode (Offline + Gemini Live): Operates offline by default; includes an optional settings modal where evaluators can enter a Google Gemini API key to activate live LLM generative chat.

⚡ 6. How to Run & Deploy the Project

The project provides four straightforward execution methods:

Method A: Instant Browser Launch (Zero Installation)

Double-click index.html (or start.bat on Windows) in file explorer. The application opens directly in any modern web browser.

Method B: Python Local Server

Method C: Node.js / NPM

# or: npx serve .

Method D: 1-Click Public Deployment (GitHub Pages)

Push the repository to GitHub and enable GitHub Pages under Settings ➔ Pages ➔ Source: GitHub Actions. GitHub automatically builds and hosts the site at:
