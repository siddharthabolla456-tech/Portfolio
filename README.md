# Siddhartha Bolla - Portfolio & AI Chatbot

My personal portfolio website and interactive AI assistant built using the MERN stack.

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Styling:** Custom CSS (Dark/Light mode with glassmorphism)

## Featured Projects

1. **Smart Feedback Management System** — Platform with automated complaint categorization, clustering duplicate grievances, and role-based access.
2. **KrishiLink AI** — Agri-commerce platform connecting farmers and buyers with ML crop yield forecasting and market price analytics.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run in development mode
```bash
npm run dev
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`

### 3. Run production build
```bash
npm start
```
Runs the full application on `http://localhost:5000`.
